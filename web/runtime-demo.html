客户集成演示：预加载 + 就绪门闩

模拟客户项目：页面一打开立即调用 preload() 预热（fetch PNG + WASM 解密）， 业务入口用 await 门闩等待——保证用户点击时解密必然已完成。

demo-app.png：加密后的业务代码（12×12，可正常显示）

正在预加载解密…

时序验证

  • 页面模块执行：调用 preload('./demo-app.png', 'demo-key-2026') 立即开始解密（不阻塞渲染）
  • 解密完成：ready Promise 变为 fulfilled，业务代码常驻内存
  • 用户调用：点击按钮 await ready 后立即执行，零等待
（点击按钮后显示结果）

客户代码（对应本项目 runtime-sdk.js）

import { Js2Png, preload } from './runtime-sdk.js';

const ready = preload('./demo-app.png', 'demo-key-2026'); ← 页面启动即预热

const biz = await ready; biz.call('greet', name); ← 业务入口门闩
